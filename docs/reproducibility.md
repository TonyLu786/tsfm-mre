# Reproducibility

## Environment

TSFM-MRE requires Python 3.11 or later and depends on NumPy, pandas, SciPy, Matplotlib and
PyYAML. Continuous integration tests Python 3.11 to 3.14 on Linux and Python 3.13 on
Windows and macOS.

```bash
pip install -e ".[dev]"   # package, pytest and ruff
pytest                     # unit, calibration and end-to-end tests
ruff check . && ruff format --check .
```

## Reference results

```bash
make reproduce
# equivalently
tsfm-mre run configs/synthetic.yaml --out results/synthetic
tsfm-mre run configs/fred_h15.yaml --out results/fred_h15
```

Each run takes about 10 seconds on a laptop. The FRED configuration downloads three
files of about 95 kB on its first run.

`results/` keeps the summaries, tables, figures and manifests of both configurations.
The forecast files and the HTML report are regenerated by the commands above; their
SHA-256 digests are recorded in each manifest.

## Determinism

- All randomness flows from the configuration seed through `numpy.random.SeedSequence`:
  the synthetic panel, the Monte Carlo replications of the ES test and the stationary
  bootstrap use separate, fixed streams.
- Forecasts are vectorised closed-form or order-statistic computations, without
  iterative optimisation.
- Tables are written with fixed precision and Unix line endings, and gzip files carry no
  timestamp. Repeated runs of the same command produce byte-identical outputs, figures
  and HTML report included; their manifests differ only in the time stamp and the run
  time. The test suite checks this for the tables and forecast files.
- Runs of the smoke configuration under Python 3.11 (pandas 2.3, SciPy 1.16,
  Matplotlib 3.10) and Python 3.12 (pandas 2.2, SciPy 1.14, Matplotlib 3.11) produce
  byte-identical tables, summaries and forecast files.

## Run manifest

`manifest.json` records:

| Field | Content |
| :--- | :--- |
| `tsfm_mre`, `git` | Package version, commit and whether the working tree was clean |
| `python`, `platform`, `dependencies` | Interpreter, operating system and library versions |
| `config`, `models` | Resolved configuration and model hyperparameters |
| `data` | Data source, downloaded files with URL, retrieval time and SHA-256, panel digest |
| `outputs` | SHA-256 digest of every file written by the run |
| `created_utc`, `runtime_seconds`, `command` | Run time stamp, duration and invocation |

Two runs agree when their `data.panel_sha256` and output digests coincide; the version
fields identify the environment that produced each result.
